# Contributing to AI & ML Acronyms

Thanks for taking the time to contribute. This glossary is a community effort and every addition or correction helps make it more useful for everyone.

## Ways to Contribute

- **Add a missing acronym** — If you've come across a term that isn't in the glossary, open a PR with the entry added in the right category, alphabetically sorted.
- **Improve a definition** — If a definition is unclear, incomplete, or outdated, edits are welcome.
- **Fix a categorization** — If an acronym feels misplaced, suggest a better fit.
- **Report an issue** — Not sure how to make the change yourself? Open an issue and describe what's missing or wrong.

## Guidelines

### Format

Every entry goes in the table under the appropriate category section in `README.md`. The format is:

```
| Acronym | Full Name | Definition |
```

- **Acronym** — The abbreviation as it appears in the literature (case-sensitive where relevant, e.g., `t-SNE`, `ZK-SNARK`).
- **Full Name** — The complete phrase the acronym stands for.
- **Definition** — A plain-language explanation. Aim for one to three sentences that describe what it is and why it matters, not just a restatement of the full name.

### Placement

- Add entries alphabetically within the correct category.
- If an acronym could reasonably belong to more than one category, place it in the one that reflects its most common usage in the literature.
- If you're unsure which category fits, mention it in your PR and we can sort it out together.

### Tone and Style

- Write definitions for readers who are smart but may be new to the specific subfield — skip unexplained jargon where possible.
- Keep it factual. This is a reference, not an opinion piece.
- Avoid promotional language.

## Submitting a Pull Request

1. Fork the repository.
2. Create a branch for your changes (`git checkout -b add-my-acronym`).
3. Make your edits in `README.md`.
4. Open a pull request with a short description of what you added or changed.

## Code of Conduct

Be respectful. Disagreements about categorization or wording are fine — just keep it constructive.
